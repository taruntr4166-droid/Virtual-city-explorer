What is Virtual City Explorer?

Virtual City Explorer is an interactive web application designed to bring essential city information together in one place. It combines weather, places, maps and local discovery features through APIs and JavaScript.

Technology Used

HTML5CSS3JavaScriptREST APIsLocalStorage

Data: Open-Meteo (weather, geocoding), Wikipedia (summaries, images), OpenStreetMap (places, map). No API keys needed.
